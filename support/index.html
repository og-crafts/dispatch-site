Support

We are a small team and we read every message.

Write to us

Email hello@ogcrafts.cloud. Say which version you use (Menu in the app, or the changelog) and whether it is the desktop app, the web app or the CLI. Please do not send secrets or whole collections; describe the request instead.

Common questions

Is Dispatch free?

Yes. There are no accounts, ads or paid tiers.

Is Dispatch open source?

Yes, under the MIT licence. The source code is on GitHub, so you can read it, build it yourself and report issues there.

Where is my data stored?

On your device. The desktop app and the web app both keep collections, environments and history in local storage (IndexedDB). If you link a workspace or collection to a folder on desktop, that folder holds them too. We run no server that receives your data.

Does it send anything besides my requests?

Usage and error reports only if you agree. On first launch Dispatch asks whether to share anonymous usage (which features are used) and reports of its own errors; both are off unless you tick them, and you can change them in Settings. It never sends your URLs, requests, responses or variables in those. The desktop app also asks GitHub whether there is a new version, when it starts and once a day. It tells you first, sends no workspace data, installs nothing without asking, and you can turn it off in Settings. From 0.3.0 the desktop app also has an assistant. It is off until you add a connection, and then it sends your questions, and what it reads to answer them, to the model you chose: Anthropic, OpenAI, an address you type or a model on this computer. We receive none of it. See the privacy policy.

What happens to my secrets?

Secret variables, passwords, tokens, keys and Authorization or Cookie headers are encrypted before they are stored, using a key that stays on the device and cannot be exported. A copy of the database moved to another device cannot read them. Exports and backups leave secrets out. An assistant key is kept the same way and is sent only to the connection it belongs to.

What if I clear my browser data?

The web app keeps its data in that browser, so clearing site data erases it. Use Menu, Export backup now and then. The desktop app is not affected by browser data.

Why does the web app say servers must allow CORS?

A web page can only read responses from servers that permit it. If a server does not, use the desktop app, which has no such rule.

Can I bring my existing collections?

Yes. Dispatch imports Postman collections and environments, Insomnia exports, Bruno folders, OpenAPI files, HAR files and curl commands, so you can try it with the requests you already have.

Are the installers signed?

Not yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch. The download page explains how to open them.

Does it sync between devices?

Not now. Export a backup, or link a workspace to a folder and keep it in git.

Is there a mobile app?

No. The web app works in a phone browser but is built for a larger screen.

How do I get help or report a problem?

Write to hello@ogcrafts.cloud.
