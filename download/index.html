No install: the web app

The same app runs in your browser and keeps its data in that browser. It can only reach servers that allow it through CORS, and it has no gRPC, mock server or collection folders. See desktop or web.

Command line

The command-line runner runs collections in CI and needs Node.js 20 or newer.

The installers are not signed yet

Windows and macOS will warn you the first time you open Dispatch. That is expected for an app without a paid code-signing certificate, and it does not mean the file is damaged.

Windows

SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway.

macOS

macOS says “Apple could not verify Dispatch is free of malware”. To open it the first time:

  1. Open the .dmg and drag Dispatch to Applications. Open Dispatch once and choose Done (not Move to Trash).
  2. Open System Settings, Privacy & Security, scroll down to the message about Dispatch and choose Open Anyway. Confirm with your password or Touch ID.
  3. Open Dispatch again and choose Open. macOS remembers this, so you only do it once.

If Open Anyway isn’t there, run this in Terminal, then open Dispatch as usual:

xattr -dr com.apple.quarantine /Applications/Dispatch.app

Linux

There is no signing warning. Install the .deb with sudo apt install ./file.deb or the .rpm with sudo dnf install ./file.rpm. For an AppImage, make it executable (chmod +x file.AppImage) and run it.

Check the SHA-256 checksum next to each download before you open it. The desktop app tells you when there is a new version and can update itself (also under Menu, Check for updates). The Linux .deb and .rpm packages don’t update themselves: download the new one here. Updates are checked against Dispatch’s own signing key before they install. If you installed a preview from before 0.1.0, it can’t update to 0.1.0: export a backup in it (Menu, Export backup), uninstall it, install 0.1.0 from this page and import the backup.

The code signing policy says how Dispatch’s installers are built and how you can check that a download is genuine.
