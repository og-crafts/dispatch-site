Code signing policy

Last updated 2026-11-25.

The Windows and macOS installers of Dispatch are not code-signed yet, so Windows SmartScreen and macOS Gatekeeper warn the first time you open Dispatch. The download page explains how to open it. This page says how the installers are made and how you can check that the file you have is the one we published.

How the installers are made

  • Every installer is built by GitHub Actions on GitHub-hosted runners, directly from the source code in the public repository og-crafts/dispatch, when a version tag is pushed.
  • The files are attached to the release on the GitHub releases page. The download page links to those same files.
  • Nothing built outside that workflow is published as a Dispatch installer.

How to check a download

  • The download page lists a SHA-256 checksum for each installer. Compare it with Get-FileHash file in PowerShell, shasum -a 256 file on macOS or sha256sum file on Linux.
  • Updates installed from inside the desktop app are checked against Dispatch’s own update signing key before they install, so a changed update is refused.

Team roles

  • Committers and reviewers: members of the og-crafts organization. Changes from anyone else arrive as pull requests and are reviewed by a member before they are merged.
  • Releases: owners of the og-crafts organization check and publish every release by hand.

Everyone in these roles uses multi-factor authentication for GitHub.

Privacy

Apart from looking for new versions on GitHub (described below, can be turned off), this program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Requests go to the addresses you send them to, and, from 0.3.0, if you add a connection to the Dispatch assistant, what you ask it goes to the model you chose (never to us). Anonymous usage and error reports are sent only if you agree when Dispatch first starts (both unticked; changeable in Settings), and the desktop app looks for new versions on GitHub unless you turn that off (it tells you first and sends no workspace data). The privacy policy has the details.

Report a problem

If you think a Dispatch file is harmful or was not built from this project’s source, write to hello@ogcrafts.cloud.
