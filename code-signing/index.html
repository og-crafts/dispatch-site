Code signing policy

Last updated 2026-11-16.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows installers of Dispatch are signed so that Windows can check they come from this project and were not changed on the way. Signing starts with the first release after the project is accepted by SignPath Foundation; earlier releases are unsigned.

What is signed

  • Only Dispatch itself: the Windows setup program and MSI package published on the GitHub releases page and on the download page.
  • Every signed file is built by GitHub Actions on GitHub-hosted runners, directly from the source code in the public repository og-crafts/dispatch. SignPath checks that origin before it signs.
  • Nothing built outside that workflow is signed, and no third-party program is signed with this certificate.

Team roles

  • Committers and reviewers: members of the og-crafts organization. Changes from anyone else arrive as pull requests and are reviewed by a member before they are merged.
  • Approvers: owners of the og-crafts organization. Every release is approved by hand in SignPath before it is signed.

Everyone in these roles uses multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Requests go only to the addresses you send them to. Anonymous usage and error reports are sent only if you agree when Dispatch first starts (both unticked; changeable in Settings), and the update check runs only when you ask or turn it on. The privacy policy has the details.

Report a problem

If you think a signed Dispatch file is harmful or was not built from this project’s source, write to hello@ogcrafts.cloud. You can also report it to SignPath at support@signpath.io.
